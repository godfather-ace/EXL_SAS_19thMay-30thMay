## Data 1 - Banking Dataset(banking_dataset.csv)
### Description
This dataset contains detailed information about various banking transactions and customer data. It has been compiled to aid in financial analysis, customer behavior studies, and predictive modeling. The dataset includes multiple attributes related to banking activities, providing a rich resource for data scientists, financial analysts, and machine learning enthusiasts.

## Data 2 - Churn Modelling Dataset(bank_churners.csv)
### Description
The Bank Churners dataset contains customer-level data from a bank, aimed at predicting customer attrition (churn). Each row represents an individual client, identified by CLIENTNUM, along with demographic and behavioral features such as age, gender, income category, and credit card usage patterns. The Attrition_Flag column indicates whether the customer has churned or remains active. This dataset is useful for building predictive models and performing customer segmentation and retention analysis.

## Data 3 - Insurance Dataset (health_insurance_dataset.csv)
### Description 
The Health Insurance dataset contains information about individuals and their health insurance policies. Each row represents a unique policyholder identified by Policy_ID. The dataset includes demographic attributes such as Age, Gender, and Region, along with health-related variables like BMI, Smoking_Status, and Pre_Existing_Conditions. Financial details such as Annual_Income, Premium_Amount, and Policy_Term_Years are also included. Additionally, policy behavior is captured through Claim_History and Has_Made_Claim. This dataset is suitable for insurance risk assessment, customer segmentation, and predictive modeling.
